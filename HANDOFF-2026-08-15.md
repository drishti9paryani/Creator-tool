```

Get-NetTCPConnection -LocalPort 3000 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }

```

### Env

`.env.local` currently holds `AI_PROVIDER=mock` and two empty key slots. Demo
mode needs nothing else — no keys, no network, no cost.

To go live, either double-click **`Set API Keys`** on the Desktop, or:

```
AI_PROVIDER=real
OPENCODE_API_KEY=...    # text/story  → opencode Zen → Gemini, cents per project
OPENAI_API_KEY=...      # images      → OpenAI, dollars per project
```

Restart the dev server after changing it. `.env*` is git-ignored.

Spend guard (live mode only): 8 images per project, 60 per hour across all
users. Override with `IMAGE_LIMIT_PER_PROJECT` / `IMAGE_LIMIT_PER_HOUR`.

## Gotchas

**The store is IndexedDB and loads asynchronously.** There is no synchronous
read. On a hard refresh or a direct link, `projects` is empty for the first
render or two. Any new screen that decides "this project doesn't exist" must
gate on `useHydrated()` from `lib/store/useHydrated.ts` first. Getting this
wrong told testers their work was gone — it shipped that way and had to be
fixed in four files.

**Names must come from curated pools; the user's idea goes only in
descriptions.** This has regressed three times with three different symptoms:
titles like "The Two Moment After", a prop named "RETIRED", a character named
"LAGOS" (from "…food trucks in Lagos"), and a character named "PEERING" (the
first word of "Peering into a mirror reveals…" — and every built-in suggestion
opens with a gerund). The rule and its exceptions live in `lib/ai/story.ts`
under `NAMING RULE`. Regression tests cover each. Do not splice keywords into
a name slot.

**Deterministic pickers collapse on modular arithmetic.** `pick(pool, seed +
variant * K)` silently returns the same entry whenever `K` is a multiple of the
pool length — this made "Regenerate options" look like a no-op twice, with two
different constants. Derive variants by hashing a composite key
(`hash("pool|variant|input")`), not by adding an offset.

**`next build` while `next dev` is running corrupts the dev server's chunks.**
They share `.next`. Stop the dev server first.

**`npm run lint` is not configured** — it drops into an interactive ESLint setup
prompt and hangs a non-interactive shell. `next build` runs linting anyway.

**`@vitejs/plugin-react` cannot be installed** — it needs vite 8, vitest 2.1.8
pins vite 5. JSX is transformed by setting `esbuild: { jsx: "automatic" }` in
`vitest.config.ts` instead. Don't "fix" this by installing the plugin.

**`npm run keys` needs a real terminal.** It refuses when stdin isn't a TTY
(an agent, a pipe, CI) and prints the command to run instead. That's deliberate,
not a bug.

**Windows line endings** — git warns `LF will be replaced by CRLF` on nearly
every commit. Cosmetic, ignore.

## Do not touch — these look wrong but are deliberate

- **Video generation returns nothing and says so.** No video model is wired. The
  Editor plays a storyboard animatic with a "not rendered video" badge. This is
  honest by design, not an unfinished feature.
- **Demo-mode art is coloured placards with initials.** Not broken image
  generation. Showing the old bundled Krishna photographs for a story about a
  retired postman was the lie this replaced. A "Demo art / Live AI" pill in the
  workspace header explains it to testers.
- **`data/outlines.ts` and `data/sampleProject.ts` were deleted.** They were
  unused canned stories, and their presence is what invited falling back to
  them. The PNGs in `public/assets/characters` and `/locations` are now unused
  but were left in place. Deleting them is safe if you want the space.
- **The wizard has no "Skip" button.** It was removed. It let a tester reach
  "Create project" with no story selected, where the button silently did
  nothing. Disabled Next with a stated reason replaced it.
- **11 controls were removed rather than wired** (Show All, Add Cut, Upload,
  hamburger, settings slider, bell, duplicate library icon, fake avatar,
  Download on asset detail, Upload Reference Image, the two-up grid that
  rendered the same image twice). They did nothing. A missing control generates
  no bug report; a dead one does.
- **No in-app settings page for API keys.** Offered and declined — a web form
  that writes credentials becomes an open door the moment the prototype is
  shared or hosted.
